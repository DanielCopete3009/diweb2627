Módulo: Diseño de Interfaces Web

Este módulo introduce los principios básicos para crear interfaces web claras, funcionales y orientadas a la experiencia del usuario.

Objetivos del módulo

  • Comprender los fundamentos del diseño de interfaces.
  • Aplicar buenas prácticas de maquetación con HTML y CSS.
  • Diseñar interfaces adaptadas a distintos dispositivos.
  • Introducir criterios básicos de accesibilidad web.

Contenidos principales

  • Color, tipografía y jerarquía visual.
  • Componentes y patrones de diseño.
  • Diseño responsive.
  • Wireframes y prototipos.
  • Accesibilidad y usabilidad.

Competencias

  • Maquetación web.
  • Diseño visual básico.
  • Diseño responsive.
  • Aplicación de principios UX/UI.

Metodología y evaluación

  • Ejercicios prácticos.
  • Prototipos y documentación.
  • Evaluación continua.
  • Proyecto final.

Este módulo forma parte del ciclo formativo de desarrollo web.
